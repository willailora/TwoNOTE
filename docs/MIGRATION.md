# OneNoteからの移行手順と制約

TwoNoteへの移行は、OneNoteでエクスポートしたファイルを読み取り、TwoNote用の暗号化保管庫へ取り込む方式です。OneNoteの画面やレイアウトをそのまま複製するものではありません。

**タイトル・本文・ノートブック名・セクション名が文字化けする可能性があります。画像の位置、順序、サイズ、文章との回り込み、自由配置は元どおりに再現できない場合があります。** 取り込み完了の表示だけで確認を終えず、元のOneNoteと見比べてください。

## 1. 原本と現在のデータを確保する

OneNote側で必要なノートを同期・保存し、エクスポートした原本を別の場所にもコピーします。TwoNoteを既に使っている場合は、メニューの「暗号化バックアップを書き出す」で現在の保管庫もバックアップしてください。復元にはバックアップ作成時のパスワードが必要です。

OneNote原本、TwoNoteの保管庫、画像添付、バックアップ、ログは公開用リポジトリの外へ保存してください。暗号化されたファイルもGitHubへ登録しません。

## 2. OneNoteで書き出す

Windows版OneNoteのエクスポート機能などで、次の対応形式を用意します。利用できる形式はOneNoteの版や環境によって異なります。

| 形式 | 取り込み対象と注意点 |
| --- | --- |
| `.onepkg` | パッケージ内のセクションを読み取ります。通常はこちらから試せます。展開後のファイル名や分類名が文字化けする場合があります。 |
| `.one` | OneNoteのセクションを読み取ります。 |
| `.mht` / `.mhtml` | 単一ファイルWebページとして書き出した本文と埋め込み画像を読み取ります。`.onepkg`で読み取りに問題がある場合の代替にも使えます。 |
| `.html` / `.htm` | 本文と、同じフォルダ配下の相対参照画像を読み取ります。画像用フォルダも一緒に保持してください。 |
| `.pdf` / `.xps` | 編集できるノートとしての直接取り込みには対応していません。原本の閲覧用として別途保管してください。 |

外部URL、共有フォルダのUNCパス、絶対パス、リンク経由の画像は自動取得しません。必要な画像は、エクスポートしたHTMLと同じフォルダ配下へ実ファイルとしてコピーしてください。画像が見つからない場合は警告されます。

## 3. WindowsのTwoNoteへ取り込む

1. TwoNoteを起動し、データの保存先と保管庫のパスワードを設定します。初回の確認は、既存データのない別の保存先で試すこともできます。
2. メニューの「OneNote・テキストを取り込み」を選び、原本を指定します。
3. 完了画面の件数と警告を確認します。警告がある場合、通常の取り込みでは読めた範囲だけが取り込まれている可能性があります。警告の内容を確認してから進めてください。
4. 左側のツリーで分類・記事を開き、本文と画像、表を原本と見比べます。
5. TwoNoteを一度閉じて開き直し、編集内容と画像が保持されていることを確認します。

OneNote原本は取り込みによって変更・削除されません。同じ原本の再取り込みは重複を抑えますが、別の場所へコピーした原本や旧版で取り込んだ記事は別記事になる場合があります。

既に取り込んだ記事に画像位置の情報がない場合は、画像が本文末尾に並ぶことがあります。同じ原本の再取り込みで、本文・添付が一致する未編集の単一版に限って順序を補完します。編集済み・競合中の記事を原本で自動上書きすることはありません。補完できない画像は、本文内で切り取り・貼り付けしたり、添付管理欄の「本文へ」から挿入し直したりして配置を調整します。

## 4. 移行後に確認する

- 記事の件数、重要なページの有無、本文の抜け、文字化け、改行の違い。
- ノートブック・セクションの分類と名前。セクション名はツリーの右クリックから変更できます。記事のタイトルや分類は編集欄でも修正できます。
- 画像の有無、本文との順序、向き、読み取れる大きさ。必要なら添付管理欄から個別に開きます。
- 表の文字、説明文、行・列の数。複雑な表は文章に変換される場合があります。セル結合やセル内画像の配置は完全には保持されません。
- 図形、手書き、装飾、リンク、添付の状態。OneNoteの自由配置や書式全般の完全再現には対応していません。
- グラフが画像として書き出されている場合、元の数値やExcelの編集データには戻せません。TwoNoteで新しく作る表・棒グラフ・折れ線グラフとは扱いが異なります。

気になるページがある場合は原本を残したまま、別形式のエクスポートや別の試験用保管庫で確認してください。移行結果を確認するまでは、OneNoteやその原本を整理・削除しないでください。

## 5. Androidへ同期する

Windows・Androidを対応する同じ世代のTwoNoteへ更新し、同じLAN/Wi-Fiへ接続します。PCで「スマホと同期」を開始し、AndroidでQRコードを読み取り、保管庫のパスワードを入力します。初回同期後は、通信を切っても端末内で閲覧・編集できます。

スマホでも日本語、画像、表、本文内の位置を確認します。記事の分類変更は同期しますが、ツリーの表示順・空の分類・開閉状態は各端末の設定です。確認後、必要に応じてAndroidの指紋・端末認証を登録します。

## パスワードを忘れた場合との違い

「パスワードを忘れた：OneNoteから作り直す」は、原本から別の保管庫を作る復旧機能です。通常の追加取り込みとは異なり、TwoNote内だけで行った編集は原本に含まれないため引き継がれません。読み取りに警告があれば切り替えを中止し、旧保管庫と原本は保持します。

TwoNote: 導入・利用前の注意
改訂日: 2026-10-23

プロジェクトの公式配布ページから ZIP を入手し、全体を展開してください。
説明書・ライセンス類も一緒に保管してください。Windows の実行ファイルは
ZIP 内から直接起動しないでください。

Windows 版 EXE は未署名のため、警告が表示される場合があります。
配布元と公開された SHA-256 を確認し、不安があれば実行を見合わせてください。
実行のために Windows の安全機能を無効化することは勧めません。
今回の再梱包では Windows 実機での動作確認を行っていません。

不安がある場合は、公開ソースと依存関係を確認し、ご自身でビルドする方法も
あります。ただし、確認や自己ビルドが安全性を保証するわけではありません。
ソース・ビルド手順: https://github.com/willailora/TwoNOTE
リンクを閲覧できない場合は、ソースの確認や公開が済んでいると判断しないでください。

ノート原本と取り込み元の OneNote ファイルは、別の場所へバックアップしてください。
大切なデータを使う前に、ダミーノートで保存・アプリの終了と再起動・バックアップ
からの復元を試してください。予定している操作で本文や画像が保持されるかも確認
してください。保管庫パスワードは別途保管してください。再発行機能はありません。
アプリの再インストールを復旧方法にしないでください。

Android 版は ZIP から APK を取り出し、配布元を確認したうえで端末の案内に従って
導入してください。既存版への上書き更新には、署名とバージョンの条件が合う必要が
あります。ノートを保全する前に既存版をアンインストールしないでください。
アンインストールによりノートが消える場合があります。今回の再梱包では Android の
インストール・更新・実機テストも行っていません。EXE/APK の実行・再ビルドはしていません。

EXE/APK 本体は 2026-10-15 の既存ビルドと同一です。今回は外部説明文と梱包のみを
更新しています。TwoNote 本体の条件は LICENSE.txt / LICENSE.ja.txt を参照し、
第三者ライセンスも保持してください。以前から実行ファイルに埋め込まれている
第三者通知も有効です。外部の本体ライセンスで第三者の権利を上書きしません。

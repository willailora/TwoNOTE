# TwoNote 2

GitHub公開に備えた、ソースのみのスナップショットです。実行ファイルは同梱していません。Windows・Androidのビルド手順は [Windows版](windows/README.md) と [Android版](android/README.md) を参照してください。

個人ノート・画像添付・OneNote原本・保管庫・認証情報・署名鍵・過去の作業履歴は含めていません。公開準備の状態とオフライン検査方法は [PUBLICATION.md](PUBLICATION.md) に記載しています。TwoNote本体は個人・企業内で無料利用でき、寄付は任意です。有料再販は禁止し、改変版を含む無料再配布は条件付きで認めます。正式条件は [LICENSE.ja.txt](LICENSE.ja.txt) / [LICENSE.txt](LICENSE.txt)、導入前の注意は [日本語](INSTALL-NOTICE.ja.txt) / [English](INSTALL-NOTICE.en.txt) を参照してください。第三者ライブラリにはそれぞれのライセンスが適用されます。

WindowsとAndroidでテキスト・画像を扱う、ローカル保存型のノートアプリです。Windows UIはPySide6（Qt）、AndroidはネイティブUIです。Tkinter・ブラウザ・WebViewは使いません。

OneNoteから移す場合は、先に [移行手順と制約](docs/MIGRATION.md) を確認してください。タイトル・本文・セクション名などに文字化けが起きる可能性があり、画像の位置・順序・自由配置を元どおりに再現できない場合もあります。移行後の目視確認が必要です。レビューや公開用画像には [ダミーデータでの確認・撮影手順](docs/DEMO_REVIEW.md) を使えます。

## 起動と既存データの移行

Windowsは `dist/TwoNote.exe`、Androidは署名付き `dist/TwoNote.apk` を使います。Windows EXEの実行にPythonは不要です。

既存のTwoNoteを使っていた場合は、旧TwoNoteServerを終了してから起動してください。

```powershell
.\dist\TwoNote.exe --data-dir ".\data"
```

このプロジェクトの `data` はEXEの近くから自動検出もします。未検出の場合はロック画面の「保存先を選ぶ」で指定してください。新規の標準保存先は `%LOCALAPPDATA%\TwoNote` です。

旧形式があれば、パスワード入力後の「移行して開く」で別の `vault-v2` フォルダへ移行します。移行結果を検証し、旧SQLite・添付・設定の暗号化バックアップを作成してから、照合できた旧ファイルを削除します。旧データが変化・使用中の場合は削除せず警告します。元のOneNoteエクスポートは削除しません。

この実装・テストではユーザーの保管庫を開いたり移行したりしていません。実データの移行は本人が新アプリでロック解除したときに行われます。

## 普段の使い方

### 2026-10-11 の保全・負荷改善

- HTML・Markdown等の取り込みでは元ファイルと参照画像も識別に含め、本文が同じ別記事を落とさないようにしました。同じ未変更ファイルの再試行は重複しません。旧版の本文ハッシュだけで取り込んだ記事は安全上別記事として追加される場合があり、既存の編集は上書きしません。
- 欠落・未取得の画像を警告します。原本からの作り直しは警告がある限り保管庫を切り替えません。通常の取り込みでは読めた本文を残し、欠落を報告します。
- 壊れたツリー設定は暗号化ファイルのまま `navigation.invalid-…enc` に退避し、ノートから表示を再作成します。並び順・開閉状態は再設定が必要ですが、本文と画像は変更しません。ツリー設定の破損だけではノートのバックアップ・復元を妨げません。
- Android 2.1.2は通常保存できない編集を `draft.enc` に暗号化退避し、次回解除時に復元します。退避上限は16MBです。容量不足などで退避も失敗した場合は警告し、完全な復元を保証しません。
- Androidのファイル選択中の画面再作成でも添付先を復元します。本文や鍵をActivityの保存状態に入れず、参照情報だけを保持します。プロバイダーが対応していれば読み取り権限を取り込み完了まで維持します。
- TLSハンドシェイク失敗時も接続を閉じます。通常保存時の検証は新しい変更分に限定し、起動時は引き続き全履歴を検証します。同じ添付への重複した存在確認も省きます。

### パスワードを忘れた場合

ロック画面の「パスワードを忘れた：OneNoteから作り直す」を押し、元の `.onepkg`（または `.one` / `.mht` 等）を選んで、新しいパスワードを2回入力してください。旧パスワードは不要です。`onenoteexportdata` が近くにあれば、原本選択時にそのフォルダを開きます。

これは旧保管庫の復号やパスワード変更ではなく、原本から別の暗号化保管庫を作る機能です。原本と旧保管庫は変更・削除しません。取り込み・画像検証がすべて成功したときだけ `active-vault.json` を更新し、次回以降も新しい保管庫を開きます。失敗・警告がある場合は切り替えません。失敗時の暗号化候補フォルダは残ることがあります。

TwoNote内だけで行った編集は原本に含まれないため引き継ぎません。新しい保管庫は `vault-v2-recovered-…` フォルダです。フォルダ全体を退避する場合は、`active-vault.json` とその参照先も含めてください。Androidの旧保管庫とは別のものになるため、スマホで利用していた場合は必要な旧データを確保してから新しい保管庫として設定します。

### 編集と保存

左側は「ノートブック → セクション → 記事」のツリー表示です。「＋分類」で空のノートブック／セクションを作れます。選択した分類で「＋記事」を押すと、そこに記事を作成します。

- 記事を別の分類にドロップすると移動します。ノートブックへ直接落とす場合は「セクション未指定」に入ります。
- 記事の上半分／下半分へ落とすと、その記事の前／後へ並べ替えます。ノートブック同士、同じノートブック内のセクション同士も並べ替えできます。
- 右クリックの「上へ移動」「下へ移動」でも順番を変更できます。分類を別ノートブックへまとめて移動する操作は対象外です。
- セクションを右クリック →「セクション名を変更…」で、文字化けした名前も任意の名前に直せます。所属記事の分類をまとめて更新し、本文・画像・履歴・表示順・開閉状態を保持します。削除済み記事や競合中の各編集版も、削除・競合状態を変えずに改名します。同じノートブック内の既存名への変更（結合）はできません。記事の改名はLAN同期にも反映します。元のOneNoteファイルは変更しません。
- 競合中・削除済みの記事は移動を止め、内容確認を優先します。未保存の入力は移動前に保存します。

記事の分類変更はノートの変更履歴として保存され、LAN同期にも反映します。手動表示順・空の分類・開閉状態は各端末の `navigation.enc` に暗号化して保持し、Windowsの通常バックアップにも含めます（復元にはこの機能対応版が必要）。並び順そのものは端末間で同期しません。Android 2.1.0にもツリー、長押しドラッグによる移動・並べ替え、セクション改名、画面全体の文字設定を実装しています。Androidでは各行の「⋮」から同じ操作を選ぶこともできます。

ウィンドウの位置・サイズ・最大化状態は次回起動時に復元します。モニター構成変更で画面外になる場合はQtの復元機能で表示可能な範囲に調整します。最小化状態では起動しません。

画面上部の「設定」から画面全体のフォント・文字サイズ（6〜48pt）を変更できます。左側のツリー、メニュー、ボタン、入力欄、本文、設定・ロック解除画面に反映し、見出しは基準サイズに比例して拡大します。大きな文字で画面に収まらない場合は外側をスクロールして操作できます。Windows標準のファイル選択画面など、OSが表示する部分はWindows側の設定に従います。

「本文のみの表示倍率」（50〜300%）は別設定です。本文上のCtrl＋マウスホイール、Ctrl＋＋／－でも本文の倍率を変えられ、Ctrl＋0で100%へ戻します。下部にも倍率ボタンがあります。フォント・文字サイズ・倍率は次回起動時も保持し、画像の再読み込み、ツリーの作り直し、ノートの再保存は行いません。

Windowsで毎回のパスワード入力を省くには、ロック解除画面の「次回起動時のロック解除」で「このWindowsユーザーで自動解除」を選び、パスワードを一度入力して「自動解除を登録して開く」を押します。既に開いている場合は「設定」→「ロック解除」で同じ項目を選び「保存」します。「毎回パスワードを入力」のままだと、PCを再起動していなくてもアプリを閉じるたびに再入力が必要です。画面に未登録／登録予定の説明を表示します。

自動解除はアプリ・PCの再起動後も有効です。パスワードは保存せず、Windowsのユーザー単位DPAPIで保管庫の鍵を保護します。同じWindowsアカウントで操作する人・アプリも解除できるため、共有アカウントでは無効にしてください。Windows Helloの指紋・PIN認証を呼び出す機能ではありません。手動ロック直後の自動解除はしませんが、PCを離れるときはWindowsもロックしてください。

自動解除は任意・初期状態オフです。保存済み鍵が使えない場合はパスワード入力へ戻ります。設定で無効にしてもノートやパスワードは変えません。鍵ファイル `windows-unlock.dpapi` は通常の `.twonote` バックアップやLAN同期に含まれず、復元・別端末・Windowsユーザー変更時にはパスワードが必要です。

DPAPIの保護範囲は [Microsoftの仕様](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata) を参照してください。画面全体のフォント・文字サイズ、本文の倍率、ウィンドウ状態は `desktop-preferences.json` に保存し、本文や鍵は入れません。

- パスワードでロック解除し、ノートを選んで本文・タイトル・分類・タグを編集できます。
- 入力が約0.7秒止まると自動保存。「保存」またはCtrl+Sでも保存します。切替・ロック・終了前にも保存します。
- Windowsの画像は「追加」または本文への貼り付けで添付できます。Android 2.1.3では記事の「添付」→「写真を選ぶ」「カメラで撮影」「ファイルを選ぶ」から追加します。Windowsは別ウィンドウ、Androidは個別の拡大表示も使えます。
- 閲覧・編集は端末内だけで完結します。本文や画像の定期再取得はありません。
- 同じノートを両端末で変更した場合は両方の編集版を残します。「編集版を統合」で本文・添付をまとめられます。タイトル等の分類情報は選択中の版を採用し、元の版は履歴に残ります。
- 削除は履歴として保存します。Windowsの「削除したノートも表示」から復元できます。

### 競合する編集版の整理（2.2.1）

「削除」は選択した編集版だけを削除済みにし、他の版は変更しません。削除済みの版は通常のツリーには表示せず、競合数にも含めません。既に旧版で削除していたものにも適用され、データの作り直しは不要です。Windowsで削除後に「削除したノートも表示」を勝手にオンにする処理も廃止しました。削除済み表示を手動でオンにした場合は「[削除]」として表示され、復元できます。Androidも設定の削除済み表示と「その他」から復元できます。

内容を混ぜずに1つだけ残したい場合は、残す版を選び、Windowsの「この版を採用」、Androidの「その他」→「この版を採用」を使います。他の版も含む履歴は保管庫に残し、選んだ本文・画像・表・グラフだけを現在の版にします。「編集版を統合」は削除されていない版だけをまとめ、削除済みの本文や添付は復活させません。確認中に同期で版が更新された場合は確定を拒否し、再確認を求めます。後から到着した未確認のオフライン編集は、引き続き競合として保持します。

## 本文内の画像・表・グラフ（2.2）

2.2.2では、表・グラフの保存・読込上限を両端末でUTF-8の2MBに統一しています。以前に保存できたのに開けなかった日本語の表も、形式の上限内ならそのまま開けます。数値は共通の10進数形式とし、全角数字・桁区切りのアンダースコアを正規化します。旧版が保存したJava形式の数値（末尾d/f・16進浮動小数）も読込時に10進表現へ変換しますが、新規入力は10進数に限定します。

表の編集画面を開いている間に同期で変更が来ても、編集開始時の本文と挿入位置を基準に保存し、別端末の変更を上書きしません。必要な場合は両方の編集版を保持します。原本の再取り込みで位置情報を補った後は、未編集の表示を最新版へ更新します。入力中の本文は勝手に読み直しません。

HTML/MHTの表の説明文（caption）は、短いものを表の見出し、長いものを本文として保持します。外部URL・絶対パス・UNC共有・ジャンクション／シンボリックリンク経由の画像は、外部の解決・読込を行う前に拒否します。必要な画像は原本と同じフォルダ配下へ実ファイルとしてコピーしてください。

Windows・Androidの両方で、本文中のカーソル位置に画像・表・棒グラフ・折れ線グラフを挿入できます。画像は本文の一部として選択し、同じ記事内で切り取り・貼り付けすると移動できます。下の添付管理欄から既存画像を再挿入・拡大表示することもできます。画像を本文から消しても添付データは残すため、Undoや再挿入が可能です。「外す」は本文内の参照も含めて添付を外します。

Windowsは「表」「グラフ」、Androidは「添付」から挿入します。表はカンマ区切りまたはExcel等からのタブ区切り（最大50行×12列）、グラフは項目名と数値の2列（見出し行なし、最大30項目）で入力します。「データを編集」で再編集でき、表示用の絵だけでなく元のデータも暗号化保存・同期します。プレビューで長い文字は省略しますが、元の値は保持します。数式計算・Excel埋め込み・任意の図形編集は対象外です。

旧ノートで位置情報が失われた画像は、まず本文末尾に表示します。閲覧だけで保存内容は変えず、編集時に位置を記録します。Windowsで同じ原本を再取り込みすると、本文と元添付が一致する単一の未削除版に限り、画像・表の順序を復元します。本文の編集・競合・添付変更がある記事は自動上書きしません。HTML/MHTの要素順、OneNoteのノード順と独立アウトラインの位置を使用します。表のセル内画像は表の直後に保持します。OneNoteの自由配置・装飾・手書き・図形の完全再現は対象外です。

位置は既存の暗号化本文内にローカル添付参照として保存し、外部URLやHTMLは実行しません。両端末をこの版へ更新してください。旧版では内部参照記法が文字として表示されます。通常入力・自動保存では画像を再取得せず、記事を開いたとき等に端末内の暗号化添付からプレビューを作ります。大量画像ではメモリ上限に達した画像をプレースホルダーにし、添付管理から個別に開けます。

## Androidとの同期

1. PCとAndroidを同じLAN/Wi-Fiにつなぎます。
2. PCで「スマホと同期」を押します。複数IPが表示される場合は、スマホと同じLANのIPを選びます。
3. 初回はAndroidでQRを読み取り、PCの保管庫パスワードを入力します。AndroidへのCA証明書のインストールは不要です。
4. 初回同期後に「指紋・端末認証」を設定できます。次回からPCやLANに接続せず、生体認証で端末内のノートを開けます。
5. 2回目からはPCの同期待受を開始し、Androidで「同期」を押します。

変更された暗号化オブジェクトだけを転送します。変更がなければ本文・画像の転送は0件です。PCの待受は同期完了・手動終了・ロック・アプリ終了で閉じ、最大15分でも停止します。通常時はlocalhostにもLANにもHTTPサーバーを立てません。

既定の同期待受ポートはTCP 8001です。Windows Firewallで許可する場合は信頼できるプライベートLANの範囲に限り、ルーターのポート開放はしないでください。PCのIP変更・バックアップ復元・端末登録解除後はAndroidの設定から再ペアリングします。

Android 8以降が対象です。Android 11以降は強い生体認証または端末の画面ロック、Android 8〜10は強い生体認証を使い、利用できない端末では保管庫パスワードで開けます。Androidをバックグラウンドへ移すと保存してロックします。

## 暗号化・バックアップ

本文・タイトル・分類・添付ファイル名・画像・同期資格情報はAES-256-GCMで保存します。PBKDF2-HMAC-SHA256（60万回）でパスワードから鍵を導出し、ランダムな保管庫鍵を保護します。同期はQRで確認した証明書を固定して検証するTLS接続です。転送するノートも暗号文のままです。

`vault-v2/config.json` は保管庫識別子・salt・暗号化された鍵を持つ設定であり、本文やパスワードは含みません。通常のノート保存にSQLiteは使いません。

- Windowsのメニュー「暗号化バックアップを書き出す」で `.twonote` ファイルを作成できます。
- ロック画面の「バックアップから復元」で、新しい空フォルダに復元できます。既存の保管庫は上書きしません。
- バックアップにはノート・添付・変更履歴を含みます。同期端末の資格情報や指紋設定は引き継がず、復元後に再ペアリングします。
- 旧形式の復旧用原本は `vault-v2/legacy-backup.enc` に別途保存します。このファイルも含めて保管したい場合は、アプリ終了後に `vault-v2` 全体をコピーしてください。

パスワード再発行機能はありません。バックアップの復元には元のパスワードが必要です。暗号化は、解除中のメモリ・OSのスワップ・既に保存されていた平文のディスク上の痕跡まで保護するものではありません。OneNoteからのエクスポート原本や、利用者が明示的に書き出した添付は暗号化の対象外です。

Androidの撮影中〜取り込み完了前の写真も、カメラとの受け渡しのためアプリ専用の内部キャッシュに未暗号化で一時保存します。保管庫への暗号化保存後・撮影中止時に削除し、取り込み失敗時は再試行のため保持します。元の端末写真は変更・削除しません。詳しくは [Android版の写真・カメラ仕様](android/README.md) を参照してください。

## OneNoteの取り込み

Windowsのメニュー「OneNote・テキストを取り込み」から `.onepkg`, `.one`, `.mht`, `.mhtml`, `.html`, `.htm`, `.txt`, `.md` を選べます。パーサーはEXEに同梱します。読み取れなかった項目は取り込み結果に表示します。本文が同一でも別ページの画像を勝手にまとめません。

`.onepkg` はWindowsの `expand.exe` で一時領域へ展開し、処理後に一時ファイルを削除します。元ファイルはそのまま残ります。PDF/XPSからの編集可能な取り込みは実装していません。

## 開発・検証

```powershell
.\windows\build_windows.ps1 -InstallDependencies
.\tools\bootstrap_android.ps1 -AcceptSdkLicense
.\android\build_android.ps1
$env:PYTHONPATH = "$PWD\.tools\python-packages;$PWD"
python -B -m unittest discover -s tests -p "test_*.py" -v
.\tools\test_android_core.ps1
.\tools\test_android_ui.ps1
.\dist\TwoNote.exe --self-test-report build\qa\packaged-smoke.json
```

PythonテストはQtをオフスクリーンで実行します。実データや作業中のデスクトップは使いません。Java側の実装との相互同期は別の契約テスト、Android画面・ライフサイクルはRobolectricで検証します。指紋センサー、実機のIME、実際のLAN/Firewallは実環境での確認が必要です。

詳細は `windows/README.md`, `android/README.md`, `docs/FORMAT_V2.md` を参照してください。v1のコードは `archive/twonote-v1-source.zip` に保存してあります。
